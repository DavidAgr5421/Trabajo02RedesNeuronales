# Despliegue de GitHub Pages: Informe Técnico y Blog

Esta carpeta contiene la publicación web estática del **Informe Técnico** y el **Blog de Investigación Aplicada** para GitHub Pages.

---

## 🌐 Estructura y Archivos

* **`index.html`**: Informe técnico principal en HTML estructurado según las normas del Trabajo 2 (Contexto, Caso de uso, Datos, Fundamentación matemática, Resultados empíricos, Scorecard, Interpretabilidad, LGD, Uso de IA y Cacería de alucinaciones).
* **`assets/blog.css`**: Hoja de estilos responsiva y tipografía técnica.
* **`assets/figura-*.png`**: Figuras y visualizaciones de soporte metodológico.
* **`blog/`**: Entrada y enlaces complementarios del blog técnico.
* **`Trabajo 2 (1).pdf`**: Documento PDF descargable directamente desde la cabecera del informe.
* **`.nojekyll`**: Instrucción para que GitHub Pages omita el procesador Jekyll y sirva los recursos estáticos directamente.
